# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues.

Report security issues directly to: `security@stellar-x402.org` (or create a private GitHub security advisory).
